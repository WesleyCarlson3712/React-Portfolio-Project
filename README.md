# Overview

This is my portfolio web app that I made as a 2 week project to learn React. This project has been my first time making any kind of website, so I have learned a lot while working on this. As of right now the website can only be hosted as a local server, but as I learn more about web developement I may make it accessible on the internet.

[Software Demo Video](http://youtube.link.goes.here)

# Web Pages
My website has 4 pages, a Home page, an About page, a Projects page, and a Contact page. You can navigate between each page via the buttons on the navigation bar at the top of the page. Because of the way react works, everything takes place on a single url with the content dinamically generated for each page.

# Development Environment

I used visual studio code for the creation of this project. All the code is written in JavaScript and HTMl, using Vite and Material UI.

# Instructions

## Prerequisite

- Download Node.js (LTS) for Windows: https://nodejs.org/en/

## Step 1 — Download the project from GitHub

1. Click the green `Code` button and choose `Download ZIP`.
2. Extract the ZIP file to a folder on your computer (for example your Desktop).
3. Open a terminal (PowerShell) and change into the project folder, for example:

```powershell
cd %USERPROFILE%\Desktop\React-Portfolio-Project
```

Adjust the path if you extracted to a different folder.

## Step 2 — Install dependencies

Run the following in the project root to install the Node.js packages declared in `package.json`:

```powershell
npm install
```

This creates a `node_modules` folder and downloads all required libraries.

## Step 3 — Run the development server

Start the Vite development server with:

```powershell
npm run dev
```

Vite will display a local URL (commonly `http://localhost:5173`). Open that URL in your browser to view the site.
